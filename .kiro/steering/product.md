# Product

**Habit Haunting** is a haunted-house-themed habit tracker. It was built with Kiro for the Kiroween 2026 hackathon (Costume Contest category).

## Guidelines
- Keep the spooky/haunted-house theme consistent in UI copy, naming, and visuals (e.g. habits as "ghosts" or "rooms", streaks as "hauntings"). Confirm theme vocabulary with the user before introducing new terms.
- Core purpose is habit tracking: create habits, mark them done, and show progress or streaks.
- Prioritize a polished, fun demo over breadth of features. Keep scope small.
